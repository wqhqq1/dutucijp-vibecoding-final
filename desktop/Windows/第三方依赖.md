# 随目录提供的运行依赖

- .NET 9 运行时：Microsoft，MIT；源代码及许可见 https://github.com/dotnet/runtime 。
- Windows App SDK 1.7.260224002 / WinUI 3：Microsoft；许可及第三方说明见 https://github.com/microsoft/WindowsAppSDK 与 https://github.com/microsoft/microsoft-ui-xaml 。
- Visual C++ 143 CRT x64：Microsoft，来自 Visual Studio `VC/Redist/MSVC/*/x64/Microsoft.VC143.CRT` 的正式可再分发文件，采用应用程序本地部署。其许可随 Visual Studio 分发条款适用。
- QRCoder 1.6.0：Raffael Herrmann 等，MIT；用于在内存中生成 TOTP 二维码。许可见 https://github.com/codebude/QRCoder/blob/master/LICENSE.txt 。

Windows 系统 DLL 和系统 WebAuthn API 由 Windows 11 提供。本目录不包含设备私钥、账户数据库、登录会话或认证器资料。`manifest.json` 记录本次实际提供的文件及 SHA-256。
