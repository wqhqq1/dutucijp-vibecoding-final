# Windows 原生客户端

Windows 11 x64。复制整个发布目录，双击 `Reconciliation.Windows.exe`，无需安装 .NET SDK、Visual Studio 或 Windows App SDK；不要只复制单个 EXE。客户端只连接已启动的 Go 服务，不启动、停止或重置后端实例。

本项目本机可先双击根目录“启动Demo.cmd”，沿用原独立实例；然后打开Windows客户端。共享后端新构建另存于 `dist/shared-backend/recon.exe`；当前本机teacher-demo程序已同步升级。发布文件自包含 .NET、Windows App SDK、Visual C++ CRT与XAML资源。已验证本机启动和复制路径迁移；无开发SDK的另一台物理电脑仍待实测。

首次打开填写完整后端地址，例如 `http://localhost:8080`，测试成功后保存并登录；“设置”中可更改地址和主题。服务不可达时仍能进入设置。切换地址会清除客户端会话及界面状态，需要重新登录。同一后端的获准地址共用原生 Passkey。默认“此后端通用凭据”沿用原 localhost RP；旧域名凭据在下拉列表选择对应身份。

后端应包含 `/api/auth/client-config` 及原生认证接口；旧构建会提示版本不兼容。局域网需服务明确配置监听，并由管理员从已有本机入口加入许可地址；详见 `docs/api/接入指南.md`。HTTPS 使用 Windows 信任的证书。

首次密码、Windows Hello/FIDO2、TOTP 和恢复码流程与网页相同。系统认证提示由本人完成。密码、认证密钥和恢复码不写日志或配置文件；恢复码请保存到私人位置。会话只保留在当前进程，关闭客户端后重新登录。

设置保存在 `%LOCALAPPDATA%/ReturnsReconciliation.Windows/settings.json`，只含地址、主题和配置状态。金额原样显示精确字符串；原始时间不转换时区。写入超时请刷新状态确认，勿连续重复提交。

开发构建：在项目根目录执行 `desktop/Windows/build.ps1`。使用本地 .NET 9、Windows SDK、Visual Studio MSBuild 和锁定的 Windows App SDK 1.7.260224002；普通 `dotnet build` 所在 SDK 缺少 PRI/Appx 任务时应使用该脚本。默认输出 `dist/windows-x64`，附有 SHA-256 清单。
