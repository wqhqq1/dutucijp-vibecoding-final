# C# 与真实 Go 服务的官方数据联调

普通 .NET 9 控制台，直接链接产品网络、设置、模型和 ViewModel。必须显式传入独立服务地址和不含秘密的结果文件；不默认连接本机正式服务。NativeWebAuthn 是拒绝实际设备调用的测试替身。

前提：另建官方两年度业务库的隔离副本，原源只读打开并核对散列，仅在新副本中准备全新认证状态；通过 `recon init-auth` 创建测试账户。启动该副本的 Go 服务，例如 `http://localhost:18199`。工具从尚未配置的管理员/财务账户正常完成随机强密码、TOTP和恢复码确认，然后只读查询官方交易、总览、证据和CSV，生成建议。它不提交正式差异修正，不保存密码/TOTP/恢复码。

```powershell
dotnet run --project desktop/Integration/Reconciliation.Integration.csproj -- http://localhost:18199 <安全结果文件绝对路径>
```

每次会消费一个新测试账户，不允许对正式业务库使用。不要为了重跑而清空现有实例。测试包括总量、每页上限、重复请求稳定性、降序、国家/地区范围、精确字符串及原时间精度；计时只覆盖C#请求，不是用户点击到完整WinUI页面渲染的耗时。未覆盖实体Passkey、手机扫码或另一台物理机器。
