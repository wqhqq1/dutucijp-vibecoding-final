## GitHub 备份与恢复

每天完成真实提交和归档后，通过 GitHub 插件保存最新项目文件、当日派生记录和原始 Git bundle。
云端 API 生成的快照提交与本地开发提交不是同一套 SHA；备份清单记录本地 HEAD、文件散列及 bundle 散列，不将云端快照时间冒充开发时间。
要还原本地完整开发历史，先从 GitHub 获取 `_备份/项目存档.bundle`，然后运行：

```powershell
git clone 项目存档.bundle restored-project
```

bundle 不包含原始数据；按记录的 UCI 地址和 SHA-256 获取数据后复现。截图、报告和 PPT 随真实工作逐步加入。
